# SkinLab · Studio prototype

Локальный кликабельный вариант полного редизайна, ветка `redesign_v2`.

Из корня репозитория:

```sh
node prototypes/redesign_v2/server.mjs
```

Открыть http://127.0.0.1:4173. Зависимости и секреты не нужны. Остановить: Ctrl+C.

## Что можно попробовать

- Сочетания: выбрать два актива через поиск, проверить правило, сохранить на полку.
- Подбор: выбрать тип кожи и задачу, открыть подходящие записи справочника.
- Мой уход: добавить/убрать активы, переключить утро/вечер, отметить шаг.
- Активы: поиск и подробная карточка.
- Профиль: сохранить настройки и переключить светлую/тёмную тему.

Обычные HTML/CSS/JS, локальные шрифты и существующие иконки SkinLab. База активов и правила читаются из `web/shared/data.js` без изменения. Прототип не проверяет и не обновляет медицинское содержание этой базы. Подбор — фильтр справочника, а полка — демонстрация интерфейса, не полноценная генерация безопасной схемы ухода.

Сервер доступен только на loopback и отдаёт явно разрешённые файлы прототипа, шрифты и два общих модуля. Папка находится вне `web`, поэтому не входит в текущий Cloudflare assets deployment. API, Telegram, подписка, оплата и прод не подключены. Сохранение использует отдельный ключ `skinlab.studio-prototype.v1` в localStorage. Отметки шагов живут только до перезагрузки.

Проверено вручную: выбор и поиск, известное/неизвестное сочетание и предупреждение, сохранение пары, вечерняя полка, подбор, светлая/тёмная тема, мобильная ширина 390 px. Проверен синтаксис JS. Production build, интеграции и Lighthouse не запускались: это изолированный статический прототип, не релиз приложения.

## Второй вариант

Текущий дизайн: светлый продуктовый интерфейс, коралловый акцент, карточки ингредиентов, верхняя навигация на десктопе и нижняя на телефоне. Первая neumorphism-версия сохранена отдельно и доступна по `/neumorphism/`. У версий разные ключи локального хранения.
