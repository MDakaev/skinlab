# Отложено (не входит в прод)

Код из этой папки **не подключён** к приложению и не кэшируется service worker'ом.
Здесь лежат наработки, которые сняты с продакшена, но могут понадобиться позже.

## scanner.js

Сканер упаковки: превью с камеры (`getUserMedia`), снимок кадра, загрузка фото из галереи.

Снят с прода, потому что распознавание состава было **заглушкой**: вместо реального
разбора этикетки возвращался случайный продукт из демо-каталога. Показывать женщине
выдуманный состав её крема нельзя — цена ошибки слишком высока.

Чтобы вернуть сканер в строй, нужно сначала закрыть распознавание по-настоящему:

1. **Штрихкод** — самый надёжный путь: barcode → `GET /api/products/:barcode`
   (бэкенд уже умеет подтягивать продукт из Open Beauty Facts).
2. **OCR состава** — как запасной вариант: фото списка INCI → текст → `POST /api/analyze`
   с полем `ingredientsText` (бэкенд уже умеет сопоставлять INCI с активами).

Ключевое правило: пока распознавание не даёт проверяемый результат, экран не должен
попадать в прод даже с пометкой «демо».
